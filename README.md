# 星屿物语 · 小小勇者与守护古树

一款**完全离线**的 2D 像素风动作冒险游戏，玩法以塞尔达系列（尤其是《缩小帽》）的经典结构为基础：
挥剑、回旋斩、探索地图、解谜地下城、收集道具和心之碎片——再加上核心玩法 **"变小"**。

不需要联网、不需要安装，所有图像和音乐都是程序实时生成的。

## 怎么开始

- **推荐：** 下载 `dist/star-isle-tales.html` 这一个文件，双击用 Chrome / Edge / Safari 打开。
- 或者下载整个文件夹，双击 `index.html`。

> 登机前先打开一次，确认能运行。飞行模式下照样能玩。

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动 |
| **J** / 空格 | 挥剑 · 对话 · 调查 · 确定 |
| **按住 J 再松开** | 回旋斩（砍倒周围所有敌人） |
| **K** | 使用道具 |
| Q / E | 切换道具 |
| I / Esc | 菜单（道具、心之碎片、地图、当前目标、存档） |
| M / F | 静音 / 全屏 |

站在**发光的树桩**上按 J，就能**变小**（再按一次变回来）。变小以后可以钻过荆棘下、树根里、墙角的小洞，进入"一切都变得巨大"的小人世界。

平板 / 手机会自动显示虚拟摇杆和按键。

## 故事

星露村的守护古树快要枯萎了——暗影巫师偷走了四颗**光之果实**，藏进了四座神殿。
古树的精灵**小叶**把变小的魔力借给你。拿上剑，把光之果实找回来吧！

| 神殿 | 位置 | 得到的道具 |
|---|---|---|
| 森林神殿 | 村子北边的迷雾森林（要变小钻过荆棘） | 回旋镖 |
| 湖底神殿 | 青草原东边的镜湖（用回旋镖打水晶开关升起桥） | 炸弹 |
| 山之洞窟 | 青草原北边的岩石山道（炸开巨石） | 跳跃羽毛 |
| 暗影之塔 | 青草原南边的古代遗迹（跳过大裂谷） | 勇者之弓 |

每座神殿里有小钥匙门、头目大门、需要变小才能钻的洞、水晶开关、裂缝墙、深坑、机关之眼、推石块机关；头目都有对应道具才能打破的弱点。

不知道下一步做什么，按 **I** 打开菜单看「当前目标」就好。

## 收集

- 心之碎片 8 片（4 片 = 多一颗心），藏在小人世界、宝箱和商店里
- 钱包升级 2 次（小人世界里）
- 商店的红药水：生命归零时自动回满

## 存档

每次切换区域、在家里床上休息都会**自动存档**；菜单里也可以手动存档。存档保存在浏览器里，请一直用同一个浏览器打开同一个文件。

## 开发

纯原生 JavaScript + Canvas，没有构建步骤。代码在 `js/`：

- `engine.js` 输入、音效、音乐 · `gfx.js` 像素图与地块 · `data.js` 道具数据
- `maps.js` 地图、小人世界和地下城生成 · `entities.js` 玩家、敌人、头目、道具
- `systems.js` 存档、道具、变小 · `ui.js` 界面 · `story.js` 剧情与 NPC · `main.js` 主循环

修改后运行 `node tools/build.js` 重新生成 `dist/star-isle-tales.html`。
