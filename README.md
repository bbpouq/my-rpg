# 星屿物语 · Star Isle Tales

一款**完全离线**的 2D 像素风 RPG，专门为长途飞行准备。
融合了三种玩法：

- 🌱 **星露谷式农场**：开垦、播种、浇水、收获、出货赚钱；四季轮换、天气、洒水器、钓鱼、采集、交朋友
- ⚔️ **塞尔达式冒险**：用剑实时战斗，探索 5 座地下城，找钥匙、推石块、射机关之眼，拿到弓箭 / 人鱼之鳞 / 炸弹 / 火焰杖，用道具打倒有弱点的头目
- 🐾 **宝可梦式收集**：51 种灵兽，草丛遇敌、回合制对战、属性克制、扔球收服、升级进化、训练家、劲敌、8 阶竞技场

没有任何外部依赖，不需要联网、不需要安装。所有图像和音乐都是程序实时生成的。

## 怎么开始

**方法一（推荐）：** 把整个文件夹下载到电脑，双击 `index.html`，用 Chrome / Edge / Safari / Firefox 打开即可。

**方法二：** 只拷贝一个文件 `dist/star-isle-tales.html`（所有代码都打包在里面），双击打开。

> 登机前先打开一次确认能运行。飞行模式下照样能玩。

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动 |
| **J** / 空格 / Z / 回车 | 挥剑攻击 · 调查 · 对话 · 确定 |
| **K** / X | 使用手中选中的道具（锄头、水壶、鱼竿、弓、炸弹…）· 取消 |
| Q / E 或 数字键 1-0 | 切换快捷栏道具 |
| I / Tab / Esc | 打开菜单（背包、灵兽、图鉴、任务、制作、系统） |
| M | 静音 |
| F | 全屏 |

平板 / 触屏设备会自动显示虚拟摇杆和按键。

## 新手指南

1. 打开小屋里**爷爷的宝箱**，拿到木剑和信。
2. 往东走到**晨星村**，找村长王伯（蓝色屋顶）。
3. 去**灵兽研究所**（绿色屋顶）领取第一只灵兽。
4. 照顾农场：锄头开垦 → 种下种子 → 每天浇水 → 成熟后面对作物按 J 收获 → 放进家旁边的**出货箱**，第二天早上自动卖钱。
5. 去农场北边的**迷雾森林**，挑战森林神殿！

菜单的「任务」页会一直显示**当前目标**，不知道该做什么时看一眼就好。

## 小贴士

- 一天大约现实时间 14 分钟。凌晨 2 点前要回家睡觉，否则会累倒并丢钱。
- 睡觉、以及每次进出建筑/切换区域时都会**自动存档**。菜单 → 系统 里也可以手动存档。
- 存档保存在浏览器里。想换设备或备份，用 菜单 → 系统 → **导出存档码**，在另一边**导入**即可。
- 灵兽体力越低越容易收服；睡眠/麻痹状态更容易。没出场的灵兽也能拿到一半经验。
- 头目都有弱点：有的要用弓箭射、有的要用炸弹炸、有的要用火烧。
- 用铜/铁/金/秘银矿在铁匠铺升级剑和工具。矿石在农场北边森林里的**矿洞**里，越深越好，每 5 层解锁升降梯。
- 村告示板每天有委托，完成可以拿报酬和好感度。拿着礼物和村民说话就能送礼。
- 地下城里的推石块谜题、点火盆谜题和清空房间都会出现宝箱。

## 内容一览

- 7 个野外区域 + 9 个室内场景
- 5 座地下城（森林神殿、潮汐洞窟、熔岩矿坑、冰晶神殿、暗影之塔），每座都有钥匙门、道具门、谜题和头目
- 无限层数的随机矿洞（每天变化），第 100 层以下有传说中的星灵
- 51 种灵兽、50 多种招式、11 种属性
- 15 种作物、13 种鱼、宝石、矿石、制作配方
- 9 位村民（好感度事件与奖励）、13 位野外训练家、劲敌阿杰、竞技场 8 阶 + 大师赛

## 开发

纯原生 JavaScript + Canvas，没有构建步骤。代码在 `js/` 目录：

- `engine.js` 输入、音效、音乐 · `gfx.js` 像素图与地块 · `data.js` 灵兽/招式/物品数据
- `maps.js` 地图、地下城与矿洞生成 · `entities.js` 玩家、敌人、头目 · `systems.js` 农场、时间、存档
- `ui.js` 菜单与界面 · `battle.js` 回合制对战 · `story.js` 剧情与 NPC · `main.js` 主循环与渲染

修改代码后运行 `node tools/build.js` 重新生成 `dist/star-isle-tales.html`。
