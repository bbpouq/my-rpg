# 豆丁物语 · 后院里的小小大冒险

一款**完全离线**的 2D 像素风动作冒险游戏。

你是住在后院门廊底下的小人**小豆**，身高还没有一颗草莓高。
**老鼠大王**偷走了照亮豆丁村的四颗**星星糖**，藏进了大人的房子里。
和萤火虫**萤萤**一起，穿过花园、门廊、浴室、厨房和地下室，把星星糖找回来吧！

不需要联网、不需要安装，所有图像和音乐都是程序实时生成的。

## 怎么开始

- **推荐：** 下载 `dist/star-isle-tales.html` 这一个文件，双击用 Chrome / Edge / Safari 打开。
- 或者下载整个文件夹，双击 `index.html`。

> 登机前先打开一次，确认能运行。飞行模式下照样能玩。

## 小人眼中的大人世界

| 区域 | 在小人眼里 | 神殿 | 得到的道具 |
|---|---|---|---|
| 后院花园 | 三叶草是大树，玫瑰刺丛是城墙 | 大花盆 | 瓶盖（回旋镖） |
| 木头门廊 | 木板缝是裂谷，还睡着一只像山一样大的橘猫 | —— | —— |
| 浴室 | 瓷砖广场、肥皂泡草丛、洗发水瓶森林 | 地漏深处 | 爆米花炸弹 |
| 厨房 | 方格地砖、方糖巨石、饼干堵住的碗柜 | 碗柜迷宫 | 弹簧鞋（跳跃） |
| 地下室 | 纸箱迷宫、灰尘团、书堆、玩具锡兵 | 罐头城堡 | 橡皮筋弹弓 |

武器是奶奶的**缝衣针**，货币是**纽扣**，回血靠**蜂蜜滴**。

站在**发光的露珠**上按 J 喝一口，就能变得和蚂蚁一样小，钻进墙缝、刺丛底下，进入蚂蚁尺度的小世界。

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动 |
| **J** / 空格 | 刺 · 对话 · 调查 · 确定 |
| **按住 J 再松开** | 回旋斩 |
| **K** | 使用道具 |
| Shift / L | 翻滚 |
| Q / E | 切换道具 |
| I / Esc | 菜单（道具、心之碎片、地图、当前目标、存档） |
| M / F | 静音 / 全屏 |

平板 / 手机会自动显示虚拟摇杆和按键。不知道下一步做什么，按 **I** 看「当前目标」。

## 收集

- 心之碎片 8 片（4 片 = 多一颗心），藏在蚂蚁小世界、宝箱和杂货铺里
- 大火柴盒（纽扣上限升级）2 个
- 蜂蜜滴：生命归零时自动回满

## 存档

每次切换区域、在家里床上休息都会**自动存档**；菜单里也可以手动存档。存档保存在浏览器里，请一直用同一个浏览器打开同一个文件。

## 开发

纯原生 JavaScript + Canvas，没有构建步骤。代码在 `js/`：

- `engine.js` 输入、音效、音乐 · `gfx.js` 像素图基础 · `art.js` 角色与地块美术 · `skin.js` 各区域场景皮肤
- `data.js` 道具 · `maps.js` 地图、小世界和地下城生成 · `entities.js` 玩家、敌人、头目
- `systems.js` 存档、道具、变小 · `ui.js` 界面 · `story.js` 剧情与 NPC · `main.js` 主循环

修改后运行 `node tools/build.js` 重新生成 `dist/star-isle-tales.html`。
